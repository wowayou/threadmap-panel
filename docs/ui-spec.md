# ThreadMap UI/UX 基准

状态：v0.2 起生效。具体数值只在 `src/ui/tokens.ts` 定义。本文规定这些数值必须满足的约束，以及交互规则。改动基准需要同时改这两处，并让 `tests/design-contract.test.ts`、`tests/widget-state.test.ts` 和 `npm run acceptance` 继续通过。

## 1. 依据

| 来源 | 采用的约束 |
| --- | --- |
| [WCAG 2.2 · 2.5.8 目标尺寸（最小）](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) | 可点击目标至少 24×24 CSS px。句中的行内链接例外 |
| [WCAG 2.2 · 2.4.11 焦点不被遮挡](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html) | 面板不能盖住论坛编辑器，聚焦元素不能被完全遮住 |
| [WCAG 2.2 · 1.4.10 重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) | 320 CSS px 宽时不出现横向滚动 |
| [WCAG 2.2 · 1.4.11 非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) | 控件边框和焦点环与相邻颜色至少 3:1；正文至少 4.5:1 |
| Discourse `variables.scss` 的 `$z-layers` | header = 1000，modal overlay = 1200 |
| Discourse `compose.scss` | 编辑器打开时 `<html>` 有 `composer-open` 类，高度在 `--composer-height` |
| [Xbox Game Bar 性能小组件](https://support.xbox.com/help/games-apps/game-setup-and-play/get-to-know-game-bar-on-windows-10)（Fluent Design） | 借鉴：可钉住的紧凑小窗、标题栏拖动、三格数字读数、一个主要操作。不借鉴：亚克力半透明（叠在任意帖子上无法保证对比度，长页面上背景模糊也影响流畅度） |
| meta.discourse.org 实测（2026-10-13） | `--header-offset` = 52px；深色模式下 `--secondary` = `#1a1a1a` |

## 2. 视觉基准

- **只用基准值**：颜色、字号、字重、行高、间距、圆角、层级全部通过 `--tm-*` 变量引用。样式里禁止写裸颜色、裸字号、裸 z-index，以及刻度外的间距（自动检查）。
- **刻度**：
  - 间距：4 / 8 / 12 / 16 / 24。
  - 字号：12 / 13 / 14 / 16 / 20 / 28。正文 13，最小 12。
  - 圆角：6 / 10 / 14 / 胶囊。
  - 动效：120ms 用于状态反馈，200ms 用于进出场。系统开启“减少动态效果”时全部取消。
- **配色**：浅色、深色两套，语义名一一对应。文字类组合 ≥ 4.5:1，控件边框和焦点环 ≥ 3:1（自动检查）。分隔线只起装饰作用，不承担识别控件的职责。
- **跟随论坛主题**：读取 `--secondary` 的亮度判断深浅色，没有该变量时退回系统偏好。论坛切换主题后，面板和原帖标注一起切换。
- **层级**：面板和贴边按钮固定在 z = 1100，即在论坛 header 之上、弹窗之下，保证登录等对话框始终可以操作。

## 3. 布局（固定区域）

展开的面板从上到下分四个区域，前三个区域高度固定，内容变化时不会跳动：

| 区域 | 高度 | 内容 | 规则 |
| --- | --- | --- | --- |
| 标题栏 | 48 | 标题、主题号、全屏、收起 | 不换行，主题号放不下时省略 |
| 标签栏 | 40 | 接龙模式：接龙 / 问题 / 规则；问答模式：问答 / 规则 | 等分 |
| 状态栏 | 36 | 载入范围、阅读位置；右侧一个操作 | 始终存在；加载时底部显示 2px 进度条 |
| 内容区 | 剩余 | 当前标签的内容 | 唯一的滚动区域，滚动不会传到页面上 |

- **位置**：面板上沿等于论坛 header 的下沿（`--header-offset`）。编辑器打开时，面板下沿等于编辑器的上沿，两者永不重叠。
- **宽度**：默认 380，可在 320–480 之间拖动或用键盘调整。视口窄于 600 时面板占满宽度，不再提供全屏。
- **全屏**：面板铺满左右；内容最大宽度 720 并居中。
- **小窗**（面板标题栏的“钉成小窗”）：
  - 尺寸固定 272×138，分标题栏 32、读数 64、底栏 40 三行；悬浮在离屏幕边缘 12px 处，背景不透明。
  - 读数三格：接龙模式为“现在该接 / 问题 / 已载入”，问答模式为“重复问题 / 提问楼 / 已载入”。点任一格展开面板，并切到对应标签。
  - 底栏放一个主要操作（“跳到 #N”或“查看”）。标题栏可以拖动，规则与贴边按钮相同。
- **贴边按钮**（面板收起时显示）：
  - 尺寸 36×76，贴在左边缘或右边缘，显示“现在该接”的字和问题数。
  - 可以拖到屏幕任意位置，松手后吸附到较近的一侧，位置会被记住。
  - 纵向位置限制在 header 和编辑器之间。
  - 键盘用户在“规则”页切换停靠的一侧。

## 4. 交互状态机

状态只有四种：收起（贴边按钮）、小窗、展开、全屏。所有切换都由 `src/ui/widget-state.ts` 的纯函数决定（有单元测试）。

| 当前状态 | 事件 | 结果 | 焦点 |
| --- | --- | --- | --- |
| 收起 | 点击贴边按钮 | 展开 | 当前标签 |
| 展开 / 全屏 | 收起按钮 | 收起 | 贴边按钮 |
| 展开 | 全屏按钮 | 全屏 | 不变 |
| 全屏 | 全屏按钮 | 展开 | 不变 |
| 全屏 | Esc | 展开 | 不变 |
| 展开 / 全屏 | 钉成小窗 | 小窗 | 小窗的“展开”按钮 |
| 小窗 | 展开按钮 / 点读数 | 展开（点读数时切到对应标签） | 当前标签 |
| 小窗 | 收起按钮、Esc | 收起 | 贴边按钮 |
| 展开 | Esc | 收起 | 贴边按钮 |
| 任意 | 点击原帖标注、问题列表里的“详情” | 展开（全屏时保持全屏），切到当前模式的首个标签（接龙或问答）并选中该楼 | 详情或问题组标题 |
| 任意 | 选中某楼 | 不变 | 不变 |

固定规则：

1. **选中和跳转分开**：选中只更新面板，不滚动论坛页面。只有“跳到 / 定位”按钮才滚动页面，到达后目标楼闪现 1.6 秒描边作为反馈。
2. **阅读位置只是提示**：它随页面滚动更新到状态栏，但不会改变已选中的楼。只有在还没有选中任何楼时，才用阅读位置作为初始选择。
3. **各标签记住自己的滚动位置**，切换标签时恢复。
4. **Esc 的作用顺序**：输入框里有文字时，Esc 先清空文字。Esc 只在焦点位于面板内时生效，不影响论坛自己的快捷键。
5. **切换主题时一切重置**：贴边按钮重新出现，面板收起，选中项清空。同一主题内跳楼不重置。
6. **原帖标注**：只在主题像接龙时显示（模式为“自动”时）。面板收起时标注仍然保留，这正是贴边模式的用途。在“规则”页可以关闭。

## 5. 内容规则

- **“接龙”页的固定顺序**：提示（如有）→ 现在该接 → 试接 → 统计 → 选中楼的详情。不随数据变化重排。
- **“问答”页的固定顺序**：先查再问 → 选中楼所在的问题组 → 统计 → 被重复问过的问题列表 → 判断方式说明。
- **主要按钮**：每个区域最多一个。“现在该接”卡片里是“跳到”；问题页工具栏里是“下一个问题”；状态栏里只在还有楼没载入时，“加载全部楼层”才用主要样式。
- **措辞**：只陈述规则判断，例如“接 #21 · 同字”“前文未载入”，不说“确认作者意图”。空状态说明原因和下一步。错误说明发生了什么、已载入的楼层是否保留、怎么继续。
- **按钮文字**：使用动词短语，不超过 6 个汉字（含楼号的除外）。图标按钮都要有 `aria-label`。

## 6. 防止漂移的检查

| 检查 | 位置 |
| --- | --- |
| 样式只用基准变量；引用的变量都已定义；两套配色的对比度 | `tests/design-contract.test.ts` |
| 状态机的每一条转换 | `tests/widget-state.test.ts` |
| 浏览器实测：小窗尺寸与位置、读数跳转、拖动吸附、Esc 收起；三个固定区域的高度、内容区独立滚动、header 与编辑器避让、深色切换、拖动吸附、24px 目标尺寸、320px 无横向滚动、Esc 与焦点回归 | `acceptance/browser.mjs` |

新增组件必须使用已有的类和变量。确实需要新的数值时，先把它加进 `tokens.ts` 和本文，再写进样式。
