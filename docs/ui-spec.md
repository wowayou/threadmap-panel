# ThreadMap UI/UX 基准

适用于当前未发布工作区。视觉数值只在 `src/ui/tokens.ts` 定义；本文规定约束与交互。修改基准须同时更新契约测试和浏览器验收，不能只改截图或放宽断言。

## 1. 依据与设计原则

| 来源 | 采用的约束 |
| --- | --- |
| [WCAG 2.2 · 2.5.8 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) | 控件至少 24×24 CSS px，句中行内链接例外；独立楼号不例外 |
| [WCAG 2.2 · 2.4.11 焦点不被遮挡](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html) | 避开论坛编辑器，聚焦控件不能被完全遮住 |
| [WCAG 2.2 · 1.4.10 重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) | 320 CSS px 不横向滚动，包括英语、长用户名和无空格正文 |
| [WCAG 2.2 · 1.4.11 非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) | 控件边框/焦点环 ≥3:1，正文 ≥4.5:1 |
| Discourse 的层级、字体变量与 composer 布局约定 | header 1000 < ThreadMap 1100 < modal overlay 1200；顶部/底部读取宿主变量 |
| [Xbox Game Bar 性能小组件](https://support.xbox.com/help/games-apps/game-setup-and-play/get-to-know-game-bar-on-windows-10) | 仅借鉴可钉住、拖动、三格数字和一个主要操作；不采用背景模糊或半透明 |

- **一个好的默认值胜过一个设置项**：自动选择不挡正文的空白；加载间隔由策略决定；不保留重复的布局/数量配置。语言偏好、站点规则与隐私授权有实际不同使用场景，才提供选择。
- **是社区阅读助手，不是另一个仪表盘**：中性色、较小圆角、主题列表与回复排版；不复制 Discourse 私有组件或任意主题 CSS。
- **范围先于结论**：显示已载入/总量与缺口；未知不画百分比；“相关回复”不能标成“正确答案”。
- **渐进展开解释**：范围数字和覆盖条常显，图例/详细口径可展开；阅读页把提问楼列表折叠，给正文留位置，不增加新的设置开关。

## 2. 视觉基准

- 样式只能引用 `--tm-*` 基准变量，不写裸颜色、字号、层级或刻度外间距。
- 间距 4 / 8 / 12 / 16 / 24；字号 12 / 13 / 14 / 16 / 20 / 28；界面正文 13，阅读正文 14，最小 12。
- 圆角 4 / 6 / 8 / 胶囊；120ms 状态反馈、200ms 出入场，系统减少动效时关闭。
- 中性（纯灰）表面与普通按钮、普通提示；唯一强调色用于主要操作、链接、选中、进度与焦点/到达描边；绿/黄/红仅表达语义状态。
- 强调色取论坛 `--tertiary` 的色相，按当前深浅表面调整明度直到满足与 tokens 相同的对比度门槛（`src/ui/accent.ts`）；已合格则原样采用。读不到、透明或无法达标时用默认蓝。不直接把任意站点颜色当作合格配色。
- 字体优先 Discourse `--font-family`，缺失用系统字体栈；不下载字体。
- 深浅色由宿主 `--secondary` 亮度判断，缺失退回系统偏好。变化时面板与原帖标注同步。此处只承诺深浅适配，不承诺与每个社区主题完全同色。
- 层级 1100，原生登录等模态框始终在上方。

## 3. 固定布局与宿主共存

面板前三个区域高度固定，内容变化不推动论坛布局：

| 区域 | 高度 | 内容 |
| --- | --- | --- |
| 标题栏 | 48 | 工具标题与主题/载入数分两行；钉住、全屏、收起；长副标题省略 |
| 标签栏 | 40 | 接龙 / 问题 / 规则；或问答 / 规则（英文为 Q&A / Settings），等分 |
| 状态栏 | 36 | 来源/阅读楼号；一个加载/取消入口；加载时 2px 进度条 |
| 内容区 | 剩余 | 唯一滚动区，不把滚动传给论坛正文 |

- 上沿位于 `--header-offset` 下方，编辑器打开时下沿位于 `--composer-height` 上方。
- 默认宽 380，可在 320–480 拖动/键盘调整。自动布局可使用更窄的可用宽度，但不小于 320；偏好宽度不因暂时不足而丢失。
- **空白优先并排**：只读测量正文、可见进度轴与侧栏；先所选侧，再另一侧。只有同时不与正文/控件相交才称为并排。不可为了露出 `111 / 5555` 而盖住正文，也不挤压/缩放论坛。
- 两侧都放不下时使用**临时侧抽屉**，贴边并明确提示“收起读帖”；不假称不遮挡。视口 ≤600px 时占满宽度并隐藏全屏入口。全屏是明确的覆盖选择，内容最大宽 720。
- `<html>/<body>` 布局变化、窗口尺寸与帖子区变化触发合并测量；不改论坛节点。站点 DOM/主题差异仍需实站验证。

### 小窗

- 固定 272×138，标题 32 / 读数 64 / 底栏 40；距边缘 12，背景不透明。
- 三格：接龙为“现在该接 / 问题 / 已载入”；问答为“重复问题 / 提问楼 / 已载入”。载入数、标签、总量分层，不把 `1060/5555` 挤在一行。
- 点读数展开对应标签；底栏只有一个主要操作。问答“阅读”是打开该问题的阅读页，不是把回复 ID 当成问题 ID。
- 标题栏可拖动、吸附；长数字有紧凑字号、完整无障碍名称与标题，不能只用省略号冒充已修复测试规模内的裁剪。

### 贴边按钮

36×76，显示链头末字或问答入口与问题数；拖动后吸附较近一侧并记住纵向比例。位置限制在页头/编辑器之间。离开屏幕边缘处补齐边框/圆角。键盘用户在规则页选停靠侧。

## 4. 窗口状态机

窗口状态为收起、小窗、展开、全屏，由 `widget-state.ts` 纯函数控制。窗口/焦点共用，标签/选中项按业务模式隔离。

| 当前状态 | 事件 | 结果 | 焦点 |
| --- | --- | --- | --- |
| 收起 | 贴边按钮 | 展开 | 当前标签 |
| 展开 / 全屏 | 收起 | 收起 | 贴边按钮 |
| 展开 | 全屏 | 全屏 | 不变 |
| 全屏 | 全屏按钮或 Esc（无内层操作时） | 展开 | 不变 |
| 展开 / 全屏 | 钉住 | 小窗 | 展开按钮 |
| 小窗 | 展开按钮 / 读数 | 展开或指定标签 | 当前标签 |
| 小窗 | 收起 / Esc | 收起 | 贴边按钮 |
| 展开 | Esc（无内层操作时） | 收起 | 贴边按钮 |
| 任意 | 原帖标注 / 问题详情 / 小窗阅读 | 展开（全屏则保持），选择对应楼 | 接龙详情或问答阅读标题 |
| 任意 | 普通阅读位置变化 | 只提示；无初始选择时可给初值 | 不变，不自动打开阅读页 |

## 5. 问答阅读与焦点

采用**问题列表 → 问题与相关回复 → 返回列表**，不叠加弹窗、第二侧栏或仅悬停可用的气泡。

1. **一步进入**：列表每项只有一个阅读入口，搜索结果同样使用。点击即显示问题与第一条相关回复，无回复时说明边界。
2. **阅读上下文**：问题标题、次数、原始首问、可展开的提问楼列表；回复显示作者/楼号、明确回复或引用哪个提问、纯文本正文与原帖入口。提问楼最多展示前 20 个并保证当前楼可见；回复证据展示前 8 项。
3. **顶部切换**：上一条/下一条位于回复正文之前，不必读到底才换回复。显式切换后聚焦新回复标题；不支持仅 hover 的必需操作。
4. **稳定 ID**：问题与当前回复分开保存。新高赞回复插入、排序变化或关联移除不会偷偷换内容；不在范围时明确说明。无回复视图后来有新回复，提供显式阅读入口，不主动打断。
5. **返回**：返回按钮可随阅读保持可达。列表隐藏但不销毁，返回恢复查询、页码、滚动与触发按钮；入口消失则回查询框。进入阅读的焦点动作须等标题挂载后才消费。
6. **恢复不抢焦点**：切规则/模式、收起/小窗后仍保留阅读状态，恢复展示不抢论坛编辑器焦点，也不重新聚焦已读回复。每个模式/标签各记自己的面板滚动。
7. **Esc 优先级**：当前可见输入有字先清空；加载确认中取消并回加载按钮；阅读页返回列表；最后才退出全屏或收起。只处理面板内按键，不注册抢占论坛的全局快捷键。
8. **原帖导航独立**：只有“跳到 / 定位 / 查看原帖 / 查看首问”和明确楼号链接才导航。已显示且身份匹配时页内滚动、高亮 1.6 秒；否则新标签 `noopener noreferrer`，不刷新分析页、不用私有路由。
9. **主题生命周期**：切主题重置临时阅读状态；缓存最多恢复合法楼层，不恢复查询、未发送输入、阅读游标或自动滚动。设置/纠正/冷却不因切主题清空。

## 6. 加载、缓存与措辞

- 默认零主动数据请求。问答页无需先去规则页开启权限，直接“选择加载”，首次授权与本次数量确认合并。默认目标 20，范围 1–100，记作下次默认；间隔固定在策略中，不作为普通设置。
- 每次确认聚焦说明并滚到内容区顶部；取消不授权。可按次选择后台继续，默认切走停止；取消、关页、换主题、错误/截止时间仍停止。
- 显示本次新增量、请求数、停止原因；未知总量不冒充全帖完成。401/403/429/验证关闭许可和冷却可见，冷却结束不自动续跑。
- 范围卡默认显示数量及最多 48 格覆盖条；图例/口径点开查看，表示数据覆盖而不是论坛阅读进度。
- 本地正文缓存默认关闭；开启前明确明文、作者元数据、账号/权限、容量/保留期边界；提供“关闭并清空”。错误可见，不能伪称已保存，也不能用重新抓帖兜底。
- 接龙内容顺序固定：提示 → 链头 → 试接 → 统计 → 详情。规则页只显示当前模式业务设置；共用项为语言、工具模式、停靠侧、补取许可、可选缓存和构建/隐私说明。
- 文案只陈述事实与规则推断。说“相关回复”，不说“最佳答案”；空状态给出可行下一步；错误解释已有数据是否保留。
- 图标按钮有无障碍名称；中文短动作尽量 ≤6 字，英语按自然短语允许换行。语言选择的 label 与 select 分开，不能让选项文本污染控件名称。
- 中文/英文均覆盖主界面、标注、许可/错误/缓存和无障碍名称；`lang` 写在脚本根节点。默认跟随论坛，未知回退英文；帖子不翻译。英语界面也不让中文接龙变成英语接龙。

## 7. 可执行约束与性能

| 检查 | 位置 |
| --- | --- |
| 变量/间距/字体/颜色、对比度、类名与布局参数一致 | `tests/design-contract.test.ts` |
| 窗口转换、模式隔离、输入/选中项与权限迁移 | `tests/widget-state.test.ts`、`mode-isolation.test.ts`、`acceptance/field.mjs` |
| 正文与进度轴同时不重叠、抽屉边界、小窗长数字、后台两种行为 | `tests/layout.test.ts`、`experience.test.ts`、`acceptance/experience.mjs` |
| 稳定回复 ID、一步阅读、返回/外部标注焦点、隐藏后不抢焦点、失效与无回复 | `tests/post-preview.test.ts`、`acceptance/workflows.mjs`、`reader.mjs` |
| 双语覆盖/参数、论坛语言优先、语言不触发重算/请求、英语反例、320px 与错误切语言 | `tests/i18n.test.ts`、`acceptance/reader.mjs` |
| 缓存默认/账号/过期/清除竞态/异常、5千与1万楼实际恢复 | `tests/post-cache.test.ts`、`acceptance/cache.mjs` |
| 1–2万楼算法预算、1万楼预留接口预算 | `tests/perf*.test.ts` |

功能测试最多 2 个 worker，性能文件在功能组后逐个运行；不放宽原超时和预算：2 万楼接龙常规 <1.5s、最坏不匹配 <3s；1 万楼问答 <2s、查询 <50ms；5,000 / 10,000 楼短帖缓存恢复含解析/分析 <2.5s、长任务 <200ms；预留只读接口在 1 万楼下检索/读取 20 楼各 <50ms。所有都是可复验的本机合成门槛，不是实站时延、峰值内存或无限规模承诺。

新增组件先复用基准；确有新数值时更新 `tokens.ts`、本文与测试。新场景不能删掉已有安全/失败路径，也不能只检查容器大小而漏掉正文被覆盖或内部数字被裁剪。
