## 发现过的失败，没有用绿灯掩盖

1. **原帖标注打开后的焦点丢失**：浏览器先复现，新单元反例也失败。根因是阅读标题尚未挂载，焦点动作就被清空；修复为匹配实际阅读状态后才消费。返回、切页/模式不抢焦点的原回归仍保留。
2. **语言选择框名称不正确**：浏览器按精确 label 无法找到控件；嵌套 label 把选项文字混入名称。改为 label 与 select 分开，保留精确无障碍查询验收，没有改成只按 CSS 找到即算通过。
3. **英文虚词影响归组**：独立测试先看到 `how / do` 进入词项；增加小型虚词集合后，enable/disable 与错误码边界通过，阈值未下调。
4. **并行整套测试中的极端 HTML 超时**：默认并发下两项既有 jsdom 场景耗时约 9.32s / 7.64s，超过原 5s 单测超时。相同代码单独跑为 2.42s / 2.98s；说明对资源争用敏感，不能据此把整套判为通过。最终限制功能组最多 2 个 worker，性能文件逐个运行；整套对应两项为 3.09s / 4.30s，通过原超时，**未修改测试数据、5s 超时、单楼预算或性能门槛**。首次失败报告保留在 `reader-unbounded-vitest.json/.log`。共享机器负载仍可能影响墙钟测量，不承诺任何环境都无抖动。

## 整体项目评估

| 方面 | 判断 | 后续门槛 |
| --- | --- | --- |
| 产品 | 本地只读定位清晰；默认可发现、有界加载，列表/阅读返回比卡片叠加一致 | 仍需真实社区用户验证术语、入口与窄屏抽屉，不能仅凭截图称“最优” |
| 架构 | 保留 core/host/ui 足够；消息结构、回复证据和内部查询边界是必要小调整 | 无实际外部客户端前不引入插件市场、供应商层或重写框架 |
| 安全/账号 | 默认不主动抓取，同源只读、跨页冷却和验证失败关闭继续成立 | 站点实际读取规则/账号配额和 403 归因仍未确认，不能承诺不封号 |
| 缓存隐私 | 有明确授权、容量、保留期、清空事务和来源提示 | 不是加密库，页面脚本/共享设备/备份可读取；同账号权限变化仍可能留下过时副本 |
| 准确性 | 结构证据可追溯，双语界面不改变判断；局部英文反例有修复 | 需要独立授权样本；目前不是语义搜索，不生成或认证答案 |
| 性能 | 原预算未放宽，新增真实缓存与接口规模测试；峰值测试并发已限制 | 全响应大小、复杂正文、长会话与真正峰值内存仍未覆盖，不宜先做推测式增量重写 |
| 兼容/分发 | Chromium 本地产物与模拟图可复核，源码指纹能区分同版本不同构建 | linux.do 实站、Firefox/Safari、Tampermonkey/Violentmonkey 组合未完成；当前无 Release |
| agent | 契约可测试，权限/传输未偷渡进运行脚本 | 必须先确定调用方、授权、外发字段、真实费用/配额、提示注入与输出验证 |
