## 性能与成本

冻结实现后的同一轮测试，性能组在其他测试完成后单独运行；保留原样本、预热与预算，仅增加测量日志：

| 合成场景 | 实测 | 原预算 |
| --- | ---: | ---: |
| 20,000 楼接龙，已知 stream | 411.63ms | < 1,500ms |
| 20,000 楼接龙，未知 stream | 382.92ms | < 1,500ms |
| 20,000 楼全部接不上 | 95.85ms | < 3,000ms |
| 10,000 楼问答归组 | 39.12ms | < 2,000ms |
| 同一问答结果查询 | 2.15ms | < 50ms |

浏览器已知 3,000 个 ID、只显示 20 楼的滚动样本没有观测到长任务（报告 0，门槛 < 200ms）；**不表示零耗时，也不是完整 3,000 楼渲染/内存测试**。这些单次本机数据不能替代真实长帖性能，更不能证明算法准确性或任意规模不卡顿。更大响应、长会话内存、增量/列表优化均列入路线图，需先拿独立瓶颈证据。

所有测试为手动、有限次本地任务：浏览器站点/资源/弹出页请求全部拦截，真实传输测试只使用本机回环；无真实论坛访问、付费 API、远端运行器、定时任务、后台常驻服务或浏览器自动安装。构建 userscript 约 611.81kB（gzip 253.40kB），demo 约 507.42kB（gzip 236.79kB）；体积警告保留，没有以提高阈值掩盖。
