# ThreadMap 安全基线

脚本运行在用户已登录的论坛页面里，能读取的内容可能包括非公开帖子。本文描述当前**未发布工作区**，保护安装者的账号和数据，不以开发方便代替权限判断。源码扫描、输入/存储契约及本地浏览器验收共同检查；静态扫描和本地通过都不能代替实站验证。

**2026-10-19 修复状态：R7 本地复验通过，实站未放行。** [最新修复记录](acceptance/progress-review-2026-10-19.md)补齐缓存启动撤销遗漏 R7，新增反例已为正式回归；403 项测试、81 项浏览器场景通过。新构建 Chrome + 油猴的实站原标签刷新 N1 根因仍未确定。下文是当前策略及明确限制，不是没有缺陷的保证。

## 承诺

| 承诺 | 实现方式 | 检查 |
| --- | --- | --- |
| 只读：不发帖、不点赞、不改论坛数据 | 主动请求只经过 `src/host/loader.ts`，仅 GET；不调用论坛写方法、按钮或表单 | 源码扫描、请求契约 |
| 不执行帖子内容 | Preact / `textContent` 渲染；HTML 只在 DOMParser 惰性文档解析，没有活动 HTML 注入、eval 或动态函数 | 源码/产物扫描、恶意资源拦截 |
| 不向第三方发送帖子 | URL 仅由数字 ID 拼接，绝对同源校验；`redirect: 'error'` 发出目标请求前拒绝跳转，包括同源跳转 | 本机双端口、构建产物拦截 |
| 不申请特权、不读取凭据 | `@grant none`，不用 GM 特权、unsafeWindow，不读写 Cookie | 元数据/源码扫描 |
| 不远程加载代码、语言包或字体 | 没有 require/resource/connect，读音与双语文案随包分发 | 元数据/地址扫描 |
| 作用范围有限 | 仅 `linux.do/t/*`、`meta.discourse.org/t/*`，禁止框架内运行 | 元数据扫描 |
| 默认不主动补取、不持久存正文 | 可从阅读页确认加载；正文缓存需独立明确开启 | 默认值、浏览器请求/存储检查 |
| 加载有界且失败可见 | 串行、请求/数量/间隔/截止时间/小时预算与冷却，出错停止，不自动重试或续跑 | 加载、跨页 guard、生命周期验收 |
| agent 只预留内部契约 | `reader-api.ts` 未接入运行入口、没有全局对象/事件桥或模型连接；无加载/写操作 | 模块契约、源码和浏览器检查 |

## 主动请求策略

数值统一由 `src/core/load-policy.ts` 定义，不是站点提供的免费额度或许可。

| 限制 | 当前策略 |
| --- | --- |
| 新增目标 | 默认 20 楼，用户按次选择 1–100；合法结果达到目标后停止，不保证补齐；主题 JSON 首批返回量不受此目标控制 |
| 请求数/批量 | 每次最多 5 请求，**含主题 JSON**；每批最多 20 数据库 ID |
| 间隔与截止 | 启动间隔至少 5 秒；每个请求含正文解析最多 20 秒；本次行动最多 5 分钟 |
| 小时预算 | 同源滚动一小时最多 60 请求，失败/取消不退还额度 |
| 正常完成/取消 | 至少冷却 60 秒 |
| 普通错误 | 至少冷却 10 分钟 |
| 401/403/429 或验证页 | 至少冷却 30 分钟，自动关闭并保存补取许可；不绕过验证 |
| 服务器要求 | 有效 Retry-After（秒数或 HTTP 日期）更长时遵守更长值，包括验证页、503 等分支 |

**授权与发现**：默认开关关闭，但“选择加载”入口可见。初次授权与本次参数放在同一个确认里；只查看或取消不授权、不请求。开启开关本身不发请求，以后每次仍要确认。权限/限流错误关闭后重新确认也不能绕过冷却。跨标签页关闭许可取消本页加载；开启不自动跨页传播，无关设置不能把关闭状态写回开启。

**后台**：默认切走标签页就取消；本次确认可选择后台继续，仅完成本次有上限任务。关页、换主题、取消或保护性错误仍停止，返回不自动续跑。浏览器冻结会影响进度，不保证后台连续执行；安全间隔/截止时间不因此取消。

**跨页协调**：Web Locks 同源互斥，不排队；请求前持久记账，刷新、换主题和重开读取同一冷却。无锁、存储异常/记录损坏或时钟倒退时禁用主动加载，已有内容仍能分析。开始前保守预留一小时冷却，正常结束再记录实际冷却；崩溃或最后写入失败不会立即恢复请求。

只协调同源、同一浏览器资料中的本脚本，不协调论坛自身、其他浏览器/脚本；不抵御用户主动清除/篡改保护记录。**不能保证不封号**。本轮没有核实真实站点当前规则、账号额度或 403 原因；所有验证使用本地模拟和拦截。不要靠反复刷新、清除记录或换 IP 做请求实验。

## 本地存储与缓存隐私

默认保存范围：

- `threadmap-prefs-v2`：设置、语言、停靠及上次加载数量，不含查询或未发送输入。
- `threadmap-overrides-v1`：本地接龙纠正（主题、帖子 ID 与关系），不含正文。
- `threadmap-load-guard-v1`：请求时刻/冷却截止时间，不含主题正文、用户名或凭据。

### 可选正文数据库

`threadmap-post-cache-v1` 是独立的 IndexedDB 数据库。默认无正文写入；用户明确开启后允许保存**未加密**的正文 HTML、作者名、时间、数据库 ID/楼号、回复与点赞元数据，用于刷新恢复。缓存控制记录包含同源、账号 ID、许可代次与容量索引。账号 ID 用于避免误展示，不是认证令牌。

| 约束 | 行为 |
| --- | --- |
| 容量 | 每站最多 3 主题、总估算 16 MiB；每主题最多 10,000 楼 / 8 MiB，超额淘汰较旧内容 |
| 保留期 | 按最后一次真实看到正文的 `seenAt` 保留 24 小时；读取/恢复和只有元数据的观测都不延长；过期不恢复，脚本运行时清理 |
| 账号与主题 | 同源、账号、主题一致才恢复；无法确认账号时不读写；已知账号状态改变/匿名会关闭清空 |
| 当前可读性 | 当前观测至少一楼有真正内容（非空白文字，或图片/媒体；引用与代码也算）才恢复；缺失正文、空串、`<p></p>`、注释、只有 `&nbsp;` 都不算 |
| 新观察优先 | 平台明确空正文（含空结构）入队撤销副本，不留空壳；启动首次快照早于异步许可返回时，在账号/许可及跨页协调核验后补处理明确清空。即使所有正文为空也可提交撤销，但不写新正文、不按 stream 删减、不恢复缓存（R7 本地回归通过）。store 字段缺失、DOM 正文为空记为“未观测”，不覆盖、不续期；占位后看到真实正文照常保存。新 stream 可排除缓存 ID |
| 清除与竞态 | 关闭并清空删除本站正文库，不删设置/纠正/冷却；写入事务内核对许可代次，清空不能被迟到写入复活 |
| 跨页与异常 | BroadcastChannel 通知其他页停止；不能协调则不启用。配额、阻塞、索引损坏或事务失败可见，缓存暂停，不靠自动抓帖补偿 |

恢复内容会标为“缓存可能过时，未联网核验”。同账号的权限或帖子内容变化无法离线全面确认；即使有当前可读楼层，也不代表旧缓存每一楼仍有权限。新 stream 与实时观测只能反映观察到的变化；DOM 占位被保守地当作“没看到”，因此 store 不可用、只能读页面元素时，作者清空正文后旧副本要等明确观测才会删除。

**剩余隐私风险**：同站脚本、扩展、共用浏览器者和浏览器资料备份可能读到副本；开放 Shadow DOM 也可被页面读取。退出检测依赖 Discourse 宿主数据，脚本不运行时不能及时清除，浏览器关闭时不能保证定时物理删除，备份副本不能由脚本抹除。共用设备不建议开启。只保证恢复已完成写入且未过期/未被淘汰的数据，不保存草稿/查询/阅读游标，不重新抓取作为恢复手段。

## 输入、预览和导航边界

- store、DOM、接口和缓存统一经过帖子校验：数据库 ID、楼号、主题/来源、批次请求 ID；异常项不丢掉同批合法楼层。
- 单楼 HTML 200,000、输出文本 20,000 UTF-16 代码单元、最多 50,000 节点；超限拒绝，不截断前缀后作完整分析。这不是整个内存会话的上限。
- 整份网络响应按实际读取字节最多 16 MiB（先查 Content-Length，再边读边计，超限取消读取）；stream 最多 500,000 个 ID，页面 store、调用方已知列表与主题 JSON 共用该上限（页面数据超限时退回页面元素，加载在发请求前拒绝）。超限拒绝时保留已交出的合法楼层，不自动重试。主题首批只标准化可能接纳的新楼及最多 100 条已有楼更新的 ID，但已选 ID 的每次出现都参与冲突检查，结论与所选目标无关。
- 接龙兄弟关系共享父楼子列表、理由只列有界预览；词组缓存按 50,000 条与 2,000,000 字符淘汰，并在离开主题时释放（F2/F5/F6 本地复验通过）。同步解析单个 16 MiB 响应仍会占用主线程，没有切片。
- 自有标注只按当前归属令牌复用、清理和剥离；同名类名或错误令牌仍是普通正文。剥离只在惰性副本执行，不删除原帖。令牌不防御同页恶意脚本。
- 回复阅读只渲染已提取纯文本，包括看起来像 HTML/提示词的字符串也只作资料；引用、代码、图片可能缺失，不应把预览当完整原帖。
- 用户明确查看原帖时，设计为已显示且身份一致才页内定位，否则原生新标签 `noopener noreferrer`；不主动调用整页导航。这是用户导航，不是后台补取。`/t/主题ID/楼层` 已按段数区分有无标题段，与生成的链接往返一致，同主题导航不再重建会话（F1 已修）。实站原标签刷新反馈（N1）根因未定，当前不能保证导航不丢状态。
- i18n（internationalization，国际化）消息为本地键与具名参数；参数不二次解释为模板、HTML 或代码。语言改变不触发联网或分析重算。原生浏览器异常的诊断文字可能由浏览器自身语言决定。

## agent 预留不等于对外开放

内部契约 v1 提供范围、问答检索、结构证据和显式指定帖子纯文本。请求长度/条数、正文每楼与总输出、快照版本/取消、字段白名单均有测试；接口不返回可修改的内部数组、用户名或原始 HTML。**正文自身仍可能含个人信息，字段最小化不是匿名化。**

当前 userscript 未导入这一模块，也没有安装全局方法、消息桥、自动导出或模型。未来真接入前必须重新决定调用方身份、按次许可、外发范围、实际费用/配额与提示注入防护。帖子中的“指令”不能变成 agent 的授权，模型不能覆盖原始结构证据或触发更多抓帖/论坛写操作。完整契约见 [reader-api.md](reader-api.md)。

## 已知宿主边界

- Discourse 内部容器只读查询，异常退回 DOM；页面脚本本就能执行逻辑、伪造数据、访问同源存储，本脚本不是同页恶意代码沙箱。
- 布局只测量正文/控件并写自己的根节点，不移动/复制/缩放论坛正文。空间不足时抽屉会覆盖，界面明确提示，不把这当成安全隔离。
- 构建 ID 是源码/配置指纹，不是签名。同页不重复初始化，但不能替换旧页面里的旧实例；安装新版后先取消旧加载，再重开主题。
- 未在 linux.do、Firefox/Safari 或不同脚本管理器完成本轮实站验收。移除旧语法依赖不等于验证全部旧浏览器；无保护能力时宁可禁用对应功能。

## 分发与报告

Release 使用可审计产物及 SHA-256；不指向 main 自动更新。当前未递增版本或发布，试用工作区要自行构建并核对规则页构建标识。发布前需类型、构建、全量单元/性能/浏览器验收和人工实站检查，先构建再检查产物。

安全问题先在 Issues 留私下联系请求，不公开利用步骤、真实正文或凭据；建立私下渠道再提供细节。维护者应启用账号双重验证。
