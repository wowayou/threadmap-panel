# ThreadMap 0.2.1

适用于 `linux.do` 和 `meta.discourse.org` 帖子页的只读油猴脚本。

## 功能

- 接龙：当前承接位置、末字与读音、本地试接、原帖标注、问题筛选与可撤销纠正。
- 普通长帖：重复提问归组、先查再问、已有回答楼层定位。
- 界面：贴边按钮、展开面板、全屏、小窗，支持深浅色、左右停靠与编辑器避让。
- 数据：默认使用已载入内容，用户主动加载时串行读取同源接口，支持取消和错误提示。

## 安装与校验

1. 安装 Tampermonkey 或 Violentmonkey。
2. 下载 Release 附件 `threadmap.user.js` 并安装，更新时手动安装新版本。
3. 可选：下载 `threadmap.user.js.sha256`，在同一目录执行 `sha256sum -c threadmap.user.js.sha256`；Windows 可用 `Get-FileHash .\threadmap.user.js -Algorithm SHA256` 比对。

## 验证范围与边界

0.2.1 的本地验证覆盖类型检查、构建、125 项单元／契约测试和 31 项浏览器验收。浏览器场景使用模拟宿主，不是所有实站与浏览器组合的支持保证。

- linux.do 实站仍需人工验收。
- 只判断已载入内容；补齐上下文可能改变结论。
- 不裁定词组是不是规范成语；接龙默认规则尚需真实样本校准。
- 问答按字面相似度归组，可能误分或漏分，不生成或验证答案。
- 大量加载受站点权限、限流、人机验证和网络影响，不自动重试或绕过验证。
