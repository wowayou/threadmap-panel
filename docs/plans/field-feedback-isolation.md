# 实测反馈：模式隔离、可选能力与原生轨迹

状态：**本地验收通过，未发布**。结果见 [实测反馈验收记录](../acceptance/field-feedback-2026-10-15.md)。接续 [上一轮本地验收](../acceptance/hardening-completion-2026-10-15.md)，不将模拟测试当作实站通过。保留现有未提交改动，不发布、不推送、不访问真实论坛做请求实验。

## 1. 已知事实与尚待确认

- 用户提供约 90 秒的实测录像；只在本机临时目录抽帧，不上传、不将真实用户名/正文/画面放入测试或仓库。
- 录像前约 50 秒的加载计数由 580 增至 1060，随后点击回答发生页面载入画面；之后才看到“最多 5 请求、至少 5 秒”的新确认提示。前半段行为与上一轮构建不一致，提示旧实例或版本混用，但没有标签栏/网络日志，不能断言导航类型或安装状态。
- 右侧面板遮住论坛原生进度轨迹是明确布局缺口。原生 `111/5555` 与数据库 ID、帖子楼层号不是同一概念，不能用自己的楼层号伪造替代。
- 用户确认 403 来自 linux.do；尚无脱敏请求路径、响应头或对照证据，不能认定全部由脚本造成，也不能宣称已经消除。先停止主动补取，勿反复刷新/换 IP 重试。
- 当前“进度保留”仅指原分析页存活时的内存状态；刷新/关页后的正文恢复没有实现。不能以自动重抓冒充恢复，也不能未经确认持久化原帖。

## 2. 本轮目标与约束

1. 显式接龙只运行接龙分析，显式问答只运行问答分析；选中项、输入、分页、滚动及原帖标注设置按模式隔离。
2. 只共享只读帖子、加载范围、原帖导航、窗口布局和同源请求保护。不能按模式拆请求预算/冷却来绕过限制。
3. 主动补取成为独立可选项，默认关闭；开启本身不发请求，每次仍需确认。403/429/验证等保护性失败立即停止并关闭此项，不自动恢复；原有锁、预算、超时、冷却继续有效。
4. 默认尽量避让可见的右侧原生轨迹，提供独立开关。只调整脚本自己的布局，不移动/克隆/改写论坛控件。窄屏、空间不足、原生全屏轨迹与脚本全屏明确保留边界；Discourse 窄屏底部进度控件本轮不处理。
5. 可见运行版本与短构建指纹；避免同一构建重复挂载。新版安装不热替换旧页面中的执行实例，不能假装旧请求已被终止。
6. 先修可复现的本地问答缺陷：高频重复问题不能因“常见词”过滤而漏掉；近似归组和回复关联可分别关闭，仍可本地搜索。只保留结构性回答证据，不把相似度当答案正确性。

不增加远端服务、自动刷新、自动续跑、跨刷新正文持久化、模型 API 密钥或后台抓取。本地预发布版本标识可以递增以便区分，不等于发布 Release。

## 3. 独立实现切片

### A. 设置、模式与请求隔离

- 设置按职责区分：接龙规则/纠正；问答近似归组/回复关联；每种模式自己的标注选择；全局的主动补取（默认关）、避让轨迹（默认开）、停靠/尺寸。
- 旧的单一标注设置迁移到两种模式的初值，之后不再互相覆盖；旧设置没有主动补取字段时保持关闭。存储失败须提示，不假称已保存。
- 共用窗口状态机，模式各自拥有标签/选中项；各视图输入、查询/预览、分页和滚动在主题内保留。切主题才重置临时状态。
- 自动模式允许识别主题类型，但使用固定默认判据，不受某一模式的本地纠正或选项干扰；显式模式完全跳过另一引擎。
- 已载入范围由独立数据层计算，不借接龙结果计算问答加载进度。
- 保护性 HTTP 错误除持久冷却外，关闭主动补取许可；关闭开关时取消本页正在进行的加载并保留合法部分。不得自动点击论坛按钮。

### B. 运行标识与宿主布局

- 构建时生成稳定的源码/构建配置指纹，在元数据注释、根节点和“规则”页可核对。开发态明确标为未打包，不能伪装成分发构建。
- 检查已有宿主标记，避免新版自身重复初始化；不能保证接管不带保护的旧脚本实例，仍须用户先取消旧加载后重新打开页面。
- 原生轨迹识别参考 Discourse 公开样式契约 `.timeline-container .topic-timeline`；跳过 `.timeline-fullscreen`。参考：[上游样式](https://github.com/discourse/discourse/blob/main/app/assets/stylesheets/common/topic-timeline.scss)，2026-10-15 已只读核对；这不证明 linux.do 当前部署的 DOM 完全一致。
- 测量可见轨迹边界，在空间足够时为右侧面板/小窗/贴边按钮留出通道；全屏是用户明确覆盖页面的选择。更新按帧合并，监听可取消，切主题释放，不轮询、不增加网络。

### C. 本地问答加固与 LLM 取舍

- 先用独立合成反例验证高频重复/常见词、不同明确错误码、空输入、引用形态和大量关联回复；不直接把实测正文当训练或测试数据。
- 词项指纹可复用重复计算；近似候选检索有明确上界，优先有区分度的词，不能以“常见词一定不相似”作错误假设。
- 保留排序、明确回复/引用和源帖子 ID。显式不同错误码不自动混为同一问题；回答去重避免大组的反复线性扫描。报告字面规则剩余的漏分/误分，不承诺语义理解。
- LLM（大语言模型）本轮不接入。后续仅在本地基线的独立样本收益不足时评估可选的语义重排/归并建议；必须先确定供应商或本地模型、实际费用/配额、外发片段范围和脱敏方式、输入/输出预算、并发/取消/失败策略及注入防护。模型结论不得覆盖原始结构证据，不产生论坛写操作，不触发更多抓取。

## 4. 验收条件

| 范围 | 必须验证 |
| --- | --- |
| 显式模式隔离 | 引擎调用计数证明问答不执行接龙、接龙不执行问答；对方设置/纠正不改变当前结果 |
| 状态/设置隔离 | 两模式往返后各自输入、选中、分页、标注设置恢复；规则页和收起/小窗不丢状态；切主题重置 |
| 可选请求 | 默认及开启时零请求；确认才发；关开关取消且保留部分；403/429/验证后许可关闭、冷却跨页有效，无自动恢复 |
| 构建诊断 | 实际构建的版本/指纹一致；重复加载脚本不生成第二套根节点/监听；安装后重新打开才运行新实例的限制明确 |
| 原生轨迹 | 含 `111/5555` 的虚构轨迹在右停靠时不被遮挡且仍可点击；左侧、关闭避让、无轨迹、隐藏/动态/缩放/空间不足/全屏/离开主题均有断言 |
| 问答 | 高频相同/改写、错误码冲突、精确/近似开关、关联开关、回复/引用与稳定预览 ID；反例先失败后修复，不靠降阈值刷通过 |
| 性能 | 原 2 万楼接龙 / 1 万楼问答 / 查询预算保留；新增高重复/多回复样本，测量后再优化；布局事件不反复重算分析 |
| 回归 | 类型、构建、所有原有单元/安全/界面测试和浏览器场景继续跑；新可选项在老加载场景中显式开启，不能删除老覆盖 |
| 成本/隐私 | 本地手动、有限样本；论坛和弹出页网络全部拦截，录像只留本机临时目录；无付费模型调用/自动安装/持续任务 |
