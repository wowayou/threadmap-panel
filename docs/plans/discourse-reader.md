状态：本地实施与验收完成，见 [本轮记录](../acceptance/discourse-reader-2026-10-16.md)；接续 [阅读体验](reader-experience.md) 与 [本地正文缓存](local-post-cache.md)。只改本地代码、文档和手动验收，不提交、不发布、不访问真实论坛。

## 基线与目标

本次接手工作区重新执行类型检查、构建、312 项单元/契约测试、67 项本地浏览器场景，全部通过。缓存、空白优先布局、有界数量加载和单次后台选择已在代码中，旧文档尚未全部更新；通过本地测试不代表实站或脚本管理器兼容。

目标：让用户知道分析范围、一步进入相关回复、能回到原来的问题列表；让英文 Discourse 社区无需读中文界面；给未来 agent（智能体程序）留下可测试的只读模块契约，而不是现在引入模型、插件市场或外发正文。

## 交互取舍

| 候选 | 收益 | 边界与决定 |
| --- | --- | --- |
| 列表里逐项展开答案 | 问答距离近 | 长答案会推走其他问题，多组展开容易失去位置；本轮不采用 |
| 鼠标悬停气泡 | 快速扫一眼 | 触屏、键盘和长代码阅读不可靠；不作为主交互 |
| 新弹窗/额外侧栏 | 可对照 | 已有侧面板，再叠一层会挤压/覆盖论坛；不采用 |
| 同一面板内的列表 → 阅读 → 返回 | 单一滚动区、窄屏可用、可保留查询与位置 | **采用**。一个入口直接打开问题与第一条相关回复；回复分页在上方，保留原帖入口；Esc 先返回列表 |

- 用“相关回复”而非“最佳/正确答案”；显示明确回复或引用了哪个提问，点赞只作排序线索。
- 问题、当前回复使用稳定帖子 ID；新数据改变顺序或关联时不得偷偷切换到另一条。
- 返回恢复列表滚动与触发按钮焦点；切设置/模式、收起/小窗后恢复展示，但不抢论坛编辑器焦点。
- 默认空白优先并排，放不下明确抽屉，不为露出进度轴遮住正文。简化层级、采用中性表面与社区式回复排版，保留可执行的对比度、320px 重排、24px 目标和长数字约束。

## 多语言

- 首批简体中文、英文；默认使用论坛 `<html lang>`，缺失才用浏览器语言，不支持的语言回退英文。可手动选择界面语言，帖子内容不翻译。
- 统一消息目录、具名插值、类型检查；错误/确认/缓存隐私文案及无障碍名称也覆盖。语言不改变分析算法和网络权限，不下载语言包。
- 中文接龙仍是中文词语工具；界面英文不等于跨语言语义归组或自动翻译。

## 架构与参考

保持 `core / host / ui` 三层。需要的是消息层、结构化回复证据、阅读状态与只读查询边界，而不是重写框架。

参考 `fishjar/kiss-translator` 的 `dev` 分支提交 [`76855fdc0a664b094b6c4309ffc9884bd4402853`](https://github.com/fishjar/kiss-translator/tree/76855fdc0a664b094b6c4309ffc9884bd4402853)：

- `src/hooks/I18n.js`：语言绑定后保持查询函数稳定；本项目采用本地类型化目录，不取远程说明。
- `src/providers/contracts.ts`、`sceneAdapter.js`、`grants.js`：能力与场景解耦、契约版本、输入输出验证、取消与授权分离。这里只预留小型只读模块 API，不移植供应商、插件或动态执行。
- `src/libs/shadowDomManager.js`：隐藏与销毁区分，保留阅读状态；沿用本项目的 Preact 与主题级生命周期，不引入 React/MUI。
- README 明确新插件/Local AI 能力主要属于扩展版，不能推定用户脚本可直接复用。参考代码为 GPL-3.0，本轮只借鉴设计思路，不复制代码或素材，不更改项目许可。

### agent 预留

内部可导入、版本化、纯只读接口，提供已载入范围、当前问答检索和指定帖子纯文本；限制查询长度、结果数和正文总长度，显式报告截断、缓存来源和过期快照/取消。不注入 `window` 全局、DOM 事件桥、自动导出、模型调用或网络传输；运行的脚本不会额外暴露正文入口。

真正接入前另行决定调用方身份、逐次授权、外发字段、供应商实际费用/配额、提示注入及返回结果验证。当前没有新增收费服务、自动化触发器、持续后台任务或依赖。
