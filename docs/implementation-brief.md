# ThreadMap 实现说明

本文描述 0.2.1 的现有实现。未来方向见 [路线图](roadmap.md)，界面约束见 [ui-spec.md](ui-spec.md)，只读与隐私约束见 [security.md](security.md)。

## 模块职责

| 路径 | 职责 |
| --- | --- |
| `src/core/chain.ts` | 提取接龙候选、按楼层推进链头、记录匹配依据与问题 |
| `src/core/readings.ts`、`phrases.ts` | 字词提取与首末字读音；数据由 CC-CEDICT 生成 |
| `src/core/questions.ts` | 提问识别、字面相似度归组、回复与引用关联、本地搜索 |
| `src/core/session.ts` | 当前主题的已载入内容、来源与阅读位置 |
| `src/core/storage.ts` | 设置和手动纠正的本地保存，不保存帖子正文 |
| `src/host` | Discourse 数据读取、路由、只读请求、原帖标注与主题配色 |
| `src/ui` | Preact 组件、面板状态、焦点与停靠交互 |
| `src/userscript.tsx` | 连接宿主与会话，负责主题生命周期及批量载入 |

## 接龙判断

接龙按楼层顺序推进，不把所有历史相同末字都当成当前应接的位置。

1. 优先考虑平台明确回复且满足规则的楼。
2. 在可调的近期窗口中，未被接走的楼优先，同字优先于同音，再比较楼层距离。
3. 更早才匹配上的结果标为回溯。为控制最坏情况开销，每个读音的更早候选搜索有数量上限，因此不是完整历史穷举。
4. 接不上时标为断链；相关前文未载入时改为无法判断，不凭数据缺口认定断链或开局。

首末字读音优先采用词典词的读音，缺失时采用单字读音。判断依赖某个多音字读音时保留待确认提示。四字表达不等于规范成语，脚本不承担成语合法性裁定。

手动纠正只改变本地判断，可以恢复自动，不修改论坛本身的回复关系。

## 问答判断

先从已载入的楼层中识别提问句，再用中文字的相邻二字片段和英文词计算加权字面相似度。当前归组阈值为 0.45，查询阈值为 0.25；为控制开销，候选索引和每组比较数量均有边界，具体以 `questions.ts` 为准。

回答只关联明确回复或引用了提问的楼，排除提问者本人对该提问的回复等情况，按点赞数和楼层排序。不生成答案，不证明引用内容确实回答了问题，也不验证回答质量。

这些是启发式规则，可能误分和漏分，默认参数尚未用真实中文长帖系统校准。

## 数据与请求生命周期

- 优先读取 Discourse 页面已经载入的数据及完整帖子 ID 顺序；接口不可用时退回解析当前页面元素，回复信息与全帖总量可能未知。
- 每个主题一个会话。同主题内跳楼与面板收起不会清空已载入内容；切换主题或离开主题页时卸载组件、监听与原帖标注。
- 用户点击“加载全部楼层”或“检查新楼层”才发起同源只读请求。帖子数据库 ID 与楼层号分开使用；批量读取每批最多 20 个 ID，批间隔 500ms。
- 已知完整帖子 ID 顺序时只补齐缺失内容；主动检查新楼层时会重新读取主题信息。
- 加载期间最多每 1.5 秒合并一次新增内容，结束、取消或失败时仍合并已经取得的内容。超过 1000 楼未载入时先说明请求量和估算耗时。
- 权限、限流、人机验证或解析异常会停止当前加载，不自动重试；页面内已经取得的帖子不因此丢失。

## 界面与状态

界面渲染在 Shadow DOM（影子文档树，用于隔离组件样式）内；原帖标注是普通按钮。收起、小窗、展开和全屏由 `widget-state.ts` 的状态转换控制，具体尺寸在 `tokens.ts` 中定义。

选中对象和阅读位置分开保存：看详情不自动跳正文，只有明确的跳转操作才滚动或导航。面板收起时仍可保留原帖标注；配色跟随宿主，布局避让论坛页头和编辑器。键盘、焦点、窄屏和减少动效的约束由界面测试覆盖。

## 验证范围

- `npm test`：链头、读音、缺口、纠正、问答、加载、安全与界面契约。
- `npm run acceptance`：本地模拟 Discourse 宿主中的实际浏览器交互，不等于实站验收。
- `npm run screenshots`：离线模拟页面运行构建产物，生成展示图，不访问真实帖子。

性能回归采用合成数据，预算见 `tests/perf.test.ts`：2 万楼接龙常规场景小于 1.5 秒，全部接不上的场景小于 3 秒；1 万楼问答归组小于 2 秒，查询小于 50 毫秒。这些是测试门槛，不是实站时延保证；论坛网络、页面元素数量与浏览器环境需另行验证。

linux.do 实站兼容性、接龙默认参数和真实中文问答归组效果仍是待验证项。
