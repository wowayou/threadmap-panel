## 架构评估与范围

保留 `core / host / ui` 分层，不重写框架、不引入通用插件运行时。现有模式隔离、共享导航、加载保护和主题生命周期足以承载本轮需求；真正需要补齐的是**展示语言、阅读状态、结构证据与程序查询契约**。

参考 `fishjar/kiss-translator` 在提交 `76855fdc0a664b094b6c4309ffc9884bd4402853` 的语言绑定、能力契约、授权/场景分离及隐藏/销毁区分；没有复制其 GPL-3.0 代码、素材或引入依赖。其扩展版插件、Local AI、跨域和动态执行能力不移植到这个 `@grant none` 的只读脚本。具体源码路径与取舍见本轮方案。

## 接龙判断

接龙按楼层顺序推进，不把所有历史相同末字都当成当前应接的位置：

1. 优先考虑平台明确回复且满足规则的楼。
2. 在近期窗口中，未被接走的楼优先，同字优先于同音，再比较楼层距离。
3. 更早才匹配上的结果标为回溯。每个读音的更早候选搜索有数量上限，不是历史穷举。
4. 接不上时标为断链；相关前文缺失时标为无法判断，不凭缺口认定断链或开局。

首末字优先用词典词的读音，缺失时采用单字读音。依赖某个多音字读音时保留待确认提示。四字表达不等于规范成语，不承担合法性裁定。手动纠正仅改变本地判断，不修改论坛回复关系。

理由存为带具名参数的消息结构，界面/标注到显示时才格式化；语言变化不触发重新建链，也不改变匹配结果。

## 模式与设置隔离

- 两种模式只共享只读帖子、载入范围、导航、窗口、语言和请求保护。显式模式只运行对应引擎；“自动”使用固定默认接龙规则、不读本地纠正来识别主题，避免规则调整让模式翻转。
- 自动模式下接龙设置或纠正有变化时，识别与展示可能分别计算一次；这是已知成本，不为复用而耦合两种业务规则。
- 载入范围由 `postCoverage` 独立计算。规则、标注、标签、选中项、试接/筛选/查询/分页/阅读回复按模式保存；草稿只在内存，切主题清空。旧单一标注设置迁移为两种模式的初值。
- 主动补取、正文缓存分别默认关闭并独立授权；问答近似归组/回复关联默认开启；原帖标注各自默认“自动”。布局自动决定，不再提供进度轴避让开关。加载数量只在本次确认选择；间隔由安全策略固定，不在规则页重复配置。
- 401/403/429 或验证页会关闭并持久保存补取许可。跨标签页关闭会取消本页加载；无关设置不能用旧值把它写回开启。开启不跨页自动传播。

## 问答判断与证据

识别已载入楼层的提问句，再用中文字的相邻二字片段与英文词计算加权字面相似度。归组阈值 0.45，查询阈值 0.25；没有为本轮改动下调阈值。

词权按去重后的提问计算；相同词项指纹直接归组。候选优先有区分度的词，只含常见词时也有界回退：单次最多 128 组、每词索引最多 128 组、每组最多比较 20 问。英文常见疑问词/虚词不参与相似度，保留否定和具体操作词；这修复了覆盖到的英文反例，不是跨语言语义理解或准确率认证。明确不同的 HTTP 错误码不自动合并。关闭近似归组后仅合并整理后完全相同的问题，搜索仍可用。

相关回复只关联更晚楼层对提问的平台回复或引用，排除提问者本人、同组提问与跨主题/来源，按点赞数和楼层排序。引用仅在惰性 DOM 中识别真实 `aside.quote[data-post]`；注释、代码、嵌套引用、非法主题和伪属性不算证据。结果按帖子对象缓存，没有 DOMParser 时不识别引用。

`QuestionCluster.answerEvidence` 记录每条回复指向的提问 ID 与 `reply / quote` 来源；同一目标同时存在时明确回复优先。界面和预留接口复用证据，不重新解析/猜测。去重使用集合。关闭关联后不把“未计算”说成“没有回答”。点赞、引用、相似度都不证明回复正确；不生成答案。

## 输入与自有标注

- store、DOM、接口和持久缓存都经过严格帖子解析。数据库 ID 与楼号必须是正安全整数，不能相互代替；明确主题必须一致，批次只接受请求的 ID。DOM 层仅解析十进制属性，没有数据库 ID 则跳过。
- 缺失回复字段为 `undefined`，不覆盖已有明确值；普通 DOM 空观测不直接推定删除。正文用 `bodyMissing` 表达 store 字段缺失、DOM 正文为空或只有空结构，与平台明确空正文区分：缺失只沿用旧正文、不续期；带来正文（含明确清空）就清除缺失标记。“有内容”由 `hasContent` 判断（文字或图片/媒体，空结构/注释/`&nbsp;` 不算）。
- 单楼 HTML 200,000、文本 20,000 个 UTF-16 代码单元，最多访问 50,000 节点。HTML 大小在 DOMParser 前检查，节点迭代访问；超限拒绝，不截断后冒充完整分析。
- 合法帖子比较正文、字段与上下文，重复读取保留对象引用。自有标注的插入、清理、惰性副本剥离和 mutation 判断共用归属令牌；同名正文不剥离。令牌不是同页恶意脚本间的权限边界。

## 数据与加载生命周期

优先读取 Discourse 已载入数据与完整帖子 ID 顺序；内部模块/容器不可用时退回当前页面元素，回复信息与总量可能未知。明确空 stream 与未知 stream 不同。

每个主题一个会话。设计上同主题定位、收起/小窗保留已载入内容；换主题或离开时卸载组件、监听和标注并取消旧加载，迟到响应不能合入新会话。路由解析与 `topicPermalink` 往返一致：首段是数字且不足三个数字段时首段即主题 ID。调整宽度的全局指针监听在松手、取消和卸载时都移除，取消恢复原宽度且不保存。

“选择加载”始终在支持该能力的宿主上可发现：初次授权和本次参数在同一个确认内完成，取消不授权。默认目标新增 20 楼，可选 1–100 并记作下次默认；本次仍最多 5 请求（含主题信息）、每批最多 20 ID、请求启动间隔至少 5 秒。主题首批的服务器返回量不受新增目标控制；不承诺补齐全帖。

已知 stream 只补缺口，已全部载入时主动“检查新楼层”重新读取主题信息。进度按合法 ID 交集统计，重复/串主题数据不能虚增。漏返或冲突会停止并交出合法部分；主题首批按目标只解析选中的 ID，但选中 ID 的每次出现都参与冲突判定。网络响应有 16 MiB 实际字节上限；页面数据、已知列表与主题 JSON 共用 50 万 stream 上限。最多每 1.5 秒合并一次；成功、取消或失败仍保留已交出的合法数据与 stream，DOM 观察不把 API 来源降级。

切后台默认停止；每次确认可选择只在本次后台继续。关页、换主题、取消、保护性错误仍停止；单次最长 5 分钟、单请求最多 20 秒，浏览器冻结不保证后台进度。没有自动恢复/重试。跨页锁、小时预算、持久冷却、Retry-After 与失败关闭见安全基线；这些不是站点额度或许可。

## 本地正文缓存

IndexedDB 异步存储独立于设置和请求冷却。仅显式授权后保存合法的已载入正文 HTML、作者/时间、楼号/ID、明确回复与点赞元数据；不保存派生文本、搜索、未发送输入或浏览器滚动位置。HTML 恢复后重新校验并惰性提取，不挂到活动文档。

- 每楼按最后一次真实看到正文的时间保留 24 小时；每站最多 3 主题，总估算预算 16 MiB；单主题最多 10,000 楼 / 8 MiB。较旧数据可被淘汰，容量与状态可见。
- 按同源、账号、主题核验；未知账号不读取/写入缓存，已知账号状态改变或匿名会关闭清空。恢复要求当前观测至少一楼有真正内容，空串、空结构占位不能通过；离线条件本就不是全面权限验证。
- 新 stream 可排除不再存在的旧缓存；明确清空入队删除副本，不受“当前可读”门槛阻挡。启动首次观测早于异步许可返回时，核验账号/许可及跨页协调后先移除恢复的缓存记录，再只补收集会话中的明确清空；不把留存正文或缺失观测当作新写入（R7 已修）。卸载时已入队、排在在途写入之后的撤销仍会提交；未完成授权核验就卸载则丢弃晚到结果。恢复/读取与只有元数据的观测都不刷新保留时间；到期不再恢复，在脚本运行时清理，关浏览器后不能按时物理删除。
- 许可代次检查、正文写入、索引更新和淘汰处于同一事务，避免关闭后迟到写入复活数据；BroadcastChannel 通知其他标签页停止。不能协调跨页清除时不启用缓存。
- 恢复按约 12ms 时间片让出主线程，最后一次合并/分析。过期、异常索引、配额、阻塞、事务中断均可见；失败暂停缓存，不靠重新抓帖补偿。

## 界面、语言与阅读状态

面板在 Shadow DOM 中渲染；原帖标注是普通按钮。中性表面、收敛圆角、论坛字体变量（缺失时系统字体）更贴近 Discourse；深浅色仍读取 `--secondary` 亮度，不把任意主题颜色直接作为可访问性保证。

中文/英文消息在 `src/i18n` 随脚本分发，包括错误、许可、缓存隐私和无障碍名称。默认 `<html lang>` 优先；没有才看浏览器语言，`zh-*` 映射简体中文，其余回退英文。用户可显式选择。只有语言改变时更新稳定的消息查询函数；正文不翻译、不请求语言包，分析理由与错误保留原结构到显示时选择语言。

问答采用**列表 → 问题与回复 → 返回**：点击列表结果直接显示问题与第一条相关回复，顶部切上一条/下一条；问题楼号收进可展开的明细，不铺满面板。列表保持挂载但隐藏；返回恢复原查询、页码、滚动位置与入口焦点，入口消失回查询框。数据新增/重排/关联失效不偷偷换回复 ID；没有回复的视图出现新回复后提供显式阅读入口。原帖标注/小窗显式请求才打开阅读，普通滚动提示不会打断选中。

Esc 在阅读页先返回列表；加载确认中先取消确认；输入框有文字先清空；最后才退出全屏或收起。焦点动作等标题真正挂载后执行；切规则/模式、收起/小窗后的恢复不抢论坛编辑器焦点。

所有原帖链接复用 `PostLink / PostNavigation`：设计为身份匹配且已显示才页内滚动、高亮，否则原生新标签并带 `noopener noreferrer`；脚本不直接调用整页刷新或私有路由，但新构建仍有实站原标签刷新反馈（审计 N1，根因未定）。预览仅为已提取纯文本；代码、引用、图片可能不完整。

宿主只读测量正文、进度轴和侧栏，按帧合并测量：在所选侧空白中寻找至少 320px，必要时缩窄或改到另一侧；空间不足就贴边临时抽屉，不为了露出进度轴继续移进正文。无需“避让”开关，不移动/缩放论坛节点，也不触发分析。小窗长数字分层显示载入和总量。具体条件和可执行约束见界面基准。
