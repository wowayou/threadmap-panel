# ThreadMap

Discourse 论坛的只读油猴脚本：在成语接龙帖中查看当前承接位置，在普通长帖中查找重复提问和已有回答。

适用页面：`linux.do/t/*`、`meta.discourse.org/t/*`。最近公开版本：0.2.1。

**项目已暂停，不再继续本轮开发，也不发布当前新版或扩大试用。** 当前判断是应用场景与相对论坛原生功能的收益尚不足以支持继续投入；问答只能提供字面归组与相关回复线索，不能保证答案准确。保留代码、测试和历史验收结果，不视为实站验收通过。未来是否重启，先回答[重启前的问题](docs/roadmap.md#重启前必须回答的问题)，不自动接着修缺陷或加功能。

**当前工作区尚未发布**：下文与截图描述本轮阅读交互、双语界面、空白优先布局、可选补取及本地正文缓存；公开的 0.2.1 不包含这些新行为。试用需要自行构建，版本号与 Release 未更新，请在“规则”页核对构建标识。

**R7 本地修复已复验，实站仍未放行**：[2026-10-19 修复记录](docs/acceptance/progress-review-2026-10-19.md)补齐了刷新启动首次全为空时的缓存撤销遗漏；403 项测试、81 项浏览器场景通过，原反例已转为正式回归。实站 Chrome + 油猴原标签刷新 N1 仍待定位；本地通过不等于真实站点兼容，暂不扩大试用。

## 功能与亮点

| 功能 | 当前能力 |
| --- | --- |
| 接龙进度 | 显示当前该接的楼层、词组末字和读音，并列出附近的并行链 |
| 原帖标注 | 标出承接楼层、断链、分叉、重复、帖内问题、多音字待确认和前文未载入 |
| 本地试接 | 输入四字词，检查能否接上当前链头、是否已经使用过；不会自动发帖 |
| 问题定位 | 按类型筛选，查看判断依据，跳到原帖；支持手动指定、不算接龙和恢复自动 |
| 长帖问答 | 字面相似归组重复提问，关联更晚楼层的明确回复/引用；点击问题一步进入相关回复，顶部切换，返回保留查询、页码、位置与焦点。不同 HTTP 错误码不自动合并；不认证答案正确性 |
| 阅读界面 | 贴边按钮、面板、全屏与小窗；自动寻找正文/进度轴之外的空白并排，放不下明确使用临时侧抽屉，不为露出进度轴去遮正文。小窗载入数与总量分层显示 |
| 多语言 | 简体中文 / English，默认跟随论坛 `<html lang>`，未支持的语言回退英文，可手动选择；只翻译界面、说明与错误，不翻译帖子或调用模型 |
| 按需加载 | 默认零主动请求，从问答/接龙页直接“选择加载”，初次授权与本次确认合并；目标 1–100 楼，默认 20。可按次选择后台继续，仍有串行、请求预算、截止时间和跨页冷却 |
| 刷新恢复 | 默认关闭的本地正文缓存；明确开启后按记录时间保留 24 小时，按账号/主题核验，有容量上限与“关闭并清空”，恢复不联网 |

接龙与问答按主题自动切换，也可以在“规则”页手动选择。两种模式的规则、本地纠正、输入、选中项和原帖标注分开保存；显式选择后只运行所选模式。判断结果是规则推断，不代表作者意图或回答的正确性。

## 安装与使用

1. 安装 Tampermonkey 或 Violentmonkey。
2. 从 [Releases](https://github.com/wowayou/threadmap-panel/releases) 下载公开版 `threadmap.user.js`；如需试用本页描述的未发布改动，按下方开发步骤自行构建后安装 `dist/threadmap.user.js`。更新需要手动安装新版。
3. 打开支持站点的主题页，点击屏幕边缘的按钮展开面板。标题栏可以收起、全屏或钉成小窗；“规则”页可以切换模式、调整当前模式的规则和原帖标注，并显示构建标识。安装新版后，已经打开的页面仍运行旧脚本：先取消正在进行的加载，再重新打开页面。
4. 默认只分析页面已载入楼层。需要更多上下文时，直接点“选择加载”，选本次新增目标（1–100，默认 20）并确认；不必先去规则页找开关。首次确认同时授权，以后每次仍需确认，取消不授权。**最多 5 次请求**（含主题信息）、每批最多 20 ID、启动间隔至少 5 秒，结束/取消至少冷却 60 秒；错误时更久，401/403/429 或验证会关闭许可。站点是否允许批量读取尚未确认，不确定时请勿加载。
5. 默认切到其他标签页会停止；确实需要时在本次确认勾选“切到其他标签页后继续本次”。最多 5 分钟，关页/换主题/取消/保护性错误仍停止，浏览器冻结可能影响进度，不自动续跑。
6. 点问题直接阅读已载入的相关回复；“返回问题列表”或 Esc 返回并保留查询与原位置。原帖入口已显示时页内定位、未显示时新标签打开。审计发现的同主题数字路由误重建会话（F1）已在工作区修复；但实站 Chrome + 油猴的原标签刷新（N1）根因仍未确认，不能把开启缓存当作不丢进度的保证。
7. “规则”页可选界面语言，也可明确开启“在本机保存已载入正文”以便刷新恢复。共用设备不建议开启；有明文与过时风险，详见下节。未开启缓存时刷新仍丢失内存里的历史楼层。

Release 附有 SHA-256 校验文件。在脚本与校验文件所在目录运行 `sha256sum -c threadmap.user.js.sha256`；Windows 可用 `Get-FileHash .\threadmap.user.js -Algorithm SHA256` 比对。

## 安全与数据

- 只读，不发帖、不点赞、不写回论坛，不把帖子数据发给第三方。
- 不申请油猴特权，不远程加载代码，读音数据随脚本分发。
- 打开面板、搜索、阅读和切语言不抓历史。仅显式确认加载时，用当前浏览器登录状态发同源只读请求；禁止自动重定向。
- 默认帖子只在页面内存。本地始终可保存设置、纠正、请求时刻/冷却截止时间，不存凭据。缓存需独立授权，与补取许可分开。
- **开启缓存后**，浏览器本地保存正文 HTML、作者和必要回复元数据：每楼按最后一次真实看到正文的时间保留 24 小时（只有元数据变化不续期），每站最多 3 主题 / 16 MiB，单主题最多 10,000 楼 / 8 MiB（估算预算）。不存未发送输入、查询或阅读游标；恢复不联网。
- 缓存是**未加密副本**，可能被同站脚本、扩展、共用浏览器者和资料备份读取。未知账号时不恢复，已知账号状态改变时关闭清空；页面只有空正文或空 HTML 结构（如 `<p></p>`）时不恢复；平台明确清空的正文会排队删除本地副本，包括刷新启动首次全为空时在账号/许可核验后补处理撤销（[R7 本地复验](docs/acceptance/progress-review-2026-10-19.md)）；只有实际落盘的撤销才能在刷新后生效。同账号权限撤销/帖子变化无法离线全面核验。过期不恢复，脚本运行时清理，浏览器关闭时无法保证物理删除。
- “关闭并清空”清除本站正文缓存，通知其他页停止；不删除设置、纠正和请求冷却。只保证恢复已完成写入且未过期/未淘汰的部分。
- 不自动重试、续跑或绕过验证。跨标签页锁或本地存储不可用时，禁止主动加载，但仍可分析页面已载入内容。请求限制只是本地自保策略，**不是站点许可、官方配额或“不封号”保证**。

实现与限制见 [安全基线](docs/security.md)。

## 已知边界

- **实站验证未完成**：linux.do 尚需人工验收；Discourse 的版本、主题及插件差异可能影响适配。自动并排依赖正文/原生控件的 DOM 测量；空间不足时明确为临时抽屉，全屏也是覆盖选择。
- **403 原因未确认**：站点返回 403 可能来自权限、登录状态、IP/防护层或其他请求。旧版“加载全部楼层”会在短时间发出大量请求，是可能诱因之一，但没有请求记录不能定论。新版关闭主动补取时不发数据请求，可用来隔离判断。
- **只覆盖已载入内容**：有缺口时显示“前文未载入”；新帖或补充上下文可能改变当前链头和问题归组。
- **异常/超限帖子不参与分析**：身份或主题不符、正文类型错误，或单楼超过 HTML 200,000 / 文本 20,000 个 UTF-16 代码单元、访问节点 50,000 的处理预算时拒绝，不截断后冒充完整帖子。这是项目上限，不是论坛发帖上限。
- **预览不等于完整原帖**：只显示提取的纯文本，引用、代码和图片可能未展示；应到原帖核对。切规则、模式、收起或小窗保留内存阅读状态；手动刷新仍会清空查询和阅读游标，即使开启正文缓存也不自动恢复这些状态。
- **不是成语裁判**：不检查词组是不是规范成语。支持独立四字短句、逗号分隔串和部分含词典词的混排文本，不会把普通长句任意切成四字片段。
- **接龙规则需要校准**：同音、声调、回看窗口和多音字处理均有规则边界，默认参数尚未用真实接龙样本系统校准。更早匹配的回溯搜索有数量上限，不保证穷举所有历史承接。
- **问答是字面匹配**：不是 AI 语义理解，也不生成答案；不同表达可能漏分，相似措辞可能误分。中文/英文启发式尚未做独立实站样本准确性校准。回复依据更晚楼层的显式回复/引用，不验证质量；界面英文也不等于跨语言语义搜索。
- **agent 仅预留接口**：新增了有版本、只读、限量与快照校验的[内部模块契约](docs/reader-api.md)，运行脚本没有全局/事件桥、没有接模型或自动外发。真正接入前仍需明确身份、授权、费用与提示注入防护。
- **页面数据接口可能变化**：优先读取 Discourse 页面内部数据，不可用时退回页面元素；退回后回复信息与全帖总量可能未知。
- **规模与网络限制**：合成数据性能测试不等于所有实站表现。大量加载仍受站点限流和网络影响；遇到 Cloudflare 验证需要用户自行完成，不绕过验证。

## 开发与验证

```sh
npm ci
npm run dev          # 本地模拟主题
npm run typecheck
npm run build        # demo + dist/threadmap.user.js
npm test             # 构建后运行，以覆盖产物许可与安全检查
npm run acceptance   # 本地浏览器验收，需先 build
npm run screenshots  # 七张离线模拟截图，需先 build
npm run readings -- path/to/cedict_ts.u8
```

本轮开发与验收使用 Node 24.18.0；当前 Vitest / Playwright 工具链不能在 Node 18 上运行。浏览器任务需预先准备可用的 Chromium，也可通过 `THREADMAP_CHROME=/absolute/path/to/chrome` 显式指定已有浏览器；缺少默认二进制时任务会失败，不自动下载或静默回退。它们是手动本地任务，不会自动访问真实帖子。

- `src/core`：接龙、问答、读音、会话和本地存储。
- `src/host`：Discourse 适配、只读加载、原帖标注与主题配色。
- `src/ui`、`src/i18n`：面板/阅读交互、设计变量与本地双语消息。
- `src/demo`、`tests`、`acceptance`：模拟宿主、单元测试与浏览器验收。
